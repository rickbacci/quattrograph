# Quattrograph

Hypotrochoid toy for Omarchy: live **R**, **r**, and **p** sliders.

## Where it lives

`~/.config/omarchy/plugins/richardb.quattrograph/`

Saved QML/JS reloads automatically. If a change does not apply:

```sh
omarchy-shell shell rescanPlugins
```

## Open it

**Super+Shift+I** toggles the overlay. Esc or the dimmed edge closes it.

```sh
omarchy-shell shell summon richardb.quattrograph '{}'
```
